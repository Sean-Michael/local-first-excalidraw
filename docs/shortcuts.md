# Keyboard shortcuts

The editor is the standard Excalidraw editor, so all of Excalidraw's own shortcuts work: tools (`V`, `R`, `A` and so on), ⌘Z and ⇧⌘Z for undo and redo, ⌘K to add a link, and the rest. Press `?` in the editor, or open **Help** in its menu, for Excalidraw's full list. This page lists only the shortcuts this project adds or changes.

On Windows and Linux, use Ctrl where this page says ⌘.

## Web editor

These work in the browser and in the macOS app, which shows the same editor.

| Shortcut | Where | What it does |
|---|---|---|
| ⇧⌘A (Ctrl+Shift+A) | Anywhere in the editor, including the assistant panel | Shows or hides the assistant |
| ⌘S | The canvas | Saves now and shows **Saved**. Drawings save automatically, so this replaces Excalidraw's save-to-file dialog |
| ⌘Z | The canvas | Undoes the last edit, including edits by the assistant and by MCP agents |

### Assistant panel

| Shortcut | What it does |
|---|---|
| Enter | Sends the message |
| Shift+Enter | New line |
| `@` | Starts a mention of a project file or another drawing |
| ↑ and ↓ | Move through the mention suggestions |
| Enter or Tab | Picks the highlighted mention |
| Escape | Closes the mention suggestions, or the panel if none are showing |

In the settings, the model field's list opens with ↓, moves with ↑ and ↓, picks with Enter and closes with Escape.

### Edit as JSON

| Shortcut | What it does |
|---|---|
| ⌘S | Saves the settings (not the drawing) |
| Tab | Inserts two spaces |
| Enter | New line with the same indent, one more after `{` or `[` |

### Drawing list, dialogs and shapes

| Shortcut | Where | What it does |
|---|---|---|
| Enter | The name field of the rename and new-folder dialogs | Confirms |
| Escape | Rename, move, new-folder and move-to-trash dialogs | Cancels |
| Escape | A row's `⋯` menu | Closes it |
| Enter | Renaming a shape in the Shapes view | Saves the name |
| Escape | Renaming a shape | Cancels |

## macOS app

| Shortcut | Menu | What it does |
|---|---|---|
| ⌘N | File → New Drawing… | Creates a drawing |
| ⌘O | File → Open… | Opens an `.excalidraw` file |
| ⇧⌘A | View → Toggle Assistant | Shows or hides the assistant |
| ⌥⌘R | View → Reload Drawing | Reloads the editor for the open drawing |
| ⌘, | Local Excalidraw → Settings… | Opens the app's settings |
| Return | The empty window | **New Drawing** |

**Add Folder…**, **Export as SVG…**, **Export as PNG…**, **Show in Finder** and **Open in Browser** are in the File menu without shortcuts. The sidebar's context menu has **Rename…**, **Duplicate** and **Move to Trash**.
